# Group 31 Oracle — Database Management Project

A database design and implementation project built using Oracle SQL / PL/SQL as part of coursework at NWU.

## What it covers
- Relational database schema design (ERD → normalised tables)
- PL/SQL stored procedures, triggers, and functions
- Data integrity enforcement through constraints and transactions
- Sample queries demonstrating joins, aggregations, and subqueries

## Tech stack
- Oracle Database
- PL/SQL
- SQL*Plus / Oracle SQL Developer

## How to run
1. Open Oracle SQL Developer (or SQL*Plus)
2. Connect to your Oracle instance
3. Run the schema creation scripts in order
4. Execute the sample data scripts to populate the database
5. Run the provided queries to verify functionality

## What I learned
Designing schemas that balance normalisation with query performance, and writing PL/SQL logic that enforces business rules at the database layer.
